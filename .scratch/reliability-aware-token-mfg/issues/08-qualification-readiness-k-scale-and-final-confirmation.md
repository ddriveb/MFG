# Qualification readiness: K-scale physics and final-policy confirmation

Type: implementation
Status: resolved
Blocked by: none

## Goal

Remove the two qualification-readiness blockers before ticket 06 can run:
parameterize the finite simultaneous-routing/population layers by explicit
Replica topology `K`, and confirm that a reported terminal policy is paired
with a forward/response environment generated by that same policy.

This ticket is readiness work only.  It does not run K-scale qualification,
holdout, or a formal MFG campaign.

## Scope

1. Add an explicit immutable `Topology(K)` contract and thread it through the
   simultaneous routing physics, population estimator, action support, and
   relevant validation/fingerprint paths.  Support exactly `K in {8,16,32,64}`
   for the qualification protocol, with four equal failure domains and one
   Logical Expert.  Preserve the existing K=8 result byte-for-byte/field-for-
   field wherever the accepted finite engine defines the reference behavior.
2. Implement the declared K scaling: fixed batch-release rate, expected batch
   size proportional to K, total arrival rate proportional to K, capacity
   proportional to K, and four domains each containing K/4 Replicas.  Do not
   emulate larger K by copying records or relabeling K=8 output.
3. Add solver final-policy confirmation.  After a provisional residual stop,
   rerun forward with the returned policy and recompute population/share and
   response residuals on the confirmed strategy--environment pair.  A
   candidate status is permitted only after that confirmation; otherwise
   preserve `not_converged`, `statistics_insufficient`, or `physical_failed`.
4. Freeze reusable episode identities/library fingerprints for iterations,
   while keeping qualification and holdout libraries independent.  Reusing a
   library must not reuse endogenous queue, action, completion, or scorer
   state.
5. Add the finite-K deviation-gain simultaneous upper-bound field and gate
   required for ticket 06.  Keep mean-field continuation and finite-K
   deviation estimands separate.

## Explicit non-scope

- No qualification or holdout execution and no artifact campaign.
- No change to historical engines or historical artifacts.
- No Hedge, placement optimization, dynamic price feedback, market clearing,
  HJB/FPK, BR selection, Nash claim, or MFG claim.
- `priced_mfg` remains the frozen fixed charge
  `0.25 * observable_queue_load_index`; it is not a dynamic price, shadow
  price, or market-equilibrium mechanism.

## Acceptance criteria

- `Topology(K)` strictly validates K, domain partition, identities, and
  fingerprints; K=8 regression covers physical, population, action-support,
  and CRN fields without changing accepted outputs.
- K=16/32/64 execute real parameterized finite physics with complete drain,
  causal observations, invariant counters, and no fixed eight-Replica
  assumptions remaining in the supported path.
- A convergence result cannot expose an unconfirmed final policy/environment
  pair; confirmation rows retain the final policy, forward fingerprints,
  response Q rows, population/share residuals, finite-K deviation diagnostic,
  and confirmation stop reason.
- Fixed reusable libraries are immutable and independent from endogenous run
  state; qualification and holdout identities remain disjoint.
- Simultaneous finite-K deviation upper-bound diagnostics are fail-closed and
  do not get relabelled as regret, Nash, or MFG evidence.
- Focused, affected, full suite, and config checks pass before resolution.

## Dependency

Ticket 06 must remain blocked until this ticket is resolved.  Resolving this
ticket does not authorize ticket 06 to start a campaign; its qualification
protocol still requires the normal review/claim workflow.
