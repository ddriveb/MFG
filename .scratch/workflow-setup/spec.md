# Clean Local Workflow Setup

## Goal

Establish a durable, local-first workflow so project rules, domain language, decisions, tickets, updates, source, and experiment artifacts remain separated.

## Scope

- Configure Local Markdown issue tracking.
- Add single-context domain documentation rules.
- Add a fixed update-report format.
- Record the accepted V1 scope and solver/evaluator separation.

## Acceptance criteria

- `AGENTS.md` points to the issue tracker and domain docs.
- Local issues have a documented file/status convention.
- Every work session has a fixed progress-report format.
- `CONTEXT.md` defines the current ubiquitous language and invariants.
- ADR-0001 records the durable V1 boundary.
